# 医院信息系统 (HIS) 测试文档

## 1. 测试概述

### 1.1 测试范围

本测试覆盖医院信息系统5大核心模块 + 用户基础模块 + AI服务模块，共**9个测试类**，**80+测试用例**。

| 测试类 | 所属模块 | 测试类型 | 用例数 |
|--------|----------|----------|--------|
| `PatientServiceTest` | 患者账户管理 | 单元测试 | 18 |
| `PatientServiceIntegrationTest` | 患者账户管理 | 集成测试 | 4 |
| `PatientServiceTest` | 模块1-患者信息管理 | 单元测试 | 10 |
| `AppointmentServiceTest` | 模块2-预约系统 | 单元测试 | 15 |
| `MedicineServiceTest` | 模块3-药品信息查询 | 单元测试 | 9 |
| `BillingServiceTest` | 模块4-医疗费用查询 | 单元测试 | 8 |
| `MedicalReportServiceTest` | 模块5-医疗报告生成 | 单元测试 | 10 |
| `AiServiceTest` | AI服务 | 单元测试 | 14 |
| `ControllerIntegrationTest` | 控制器层 | 集成测试 | 10 |

### 1.2 测试策略

- **单元测试**：使用 Mockito 隔离依赖，测试 Service 层业务逻辑
- **集成测试**：使用 MockMvc + SpringBootTest 测试 Controller 层 HTTP 请求链路及 UserService 完整流程
- **AI 服务测试**：Mock `ChatLanguageModel`，不调用真实 Qwen API，验证 JSON 解析和降级逻辑
- **工具类测试**：直接测试 `EncodePassword`、`MatchPassword`、`RegexTool` 等纯函数

### 1.3 技术栈

| 项目 | 版本 |
|------|------|
| JUnit 5 | 5.10.x (Spring Boot 3.2.5内置) |
| Mockito | 5.x (spring-boot-starter-test内置) |
| Spring Boot Test | 3.2.5 |
| MockMvc | 6.x (Spring框架内置) |

## 5. 测试环境配置

### 5.1 测试数据库

集成测试使用独立的 `his_test` 数据库，避免污染开发数据：

```sql
CREATE DATABASE IF NOT EXISTS his_test DEFAULT CHARACTER SET utf8mb4;
USE his_test;
-- 执行 sql/his_schema.sql 中的建表语句
```

### 5.2 测试配置文件

`application-test.yaml` 关键配置：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/his_test?...  # 独立测试库
  data:
    redis:
      database: 1  # 使用不同Redis DB
ai:
  qwen:
    api-key: test-api-key  # 测试环境使用假key
```

### 5.3 AI服务Mock说明

单元测试中，所有AI服务（`ChatLanguageModel`）均通过 Mockito Mock，**不会调用真实Qwen API**：
- 避免测试依赖外部API可用性
- 避免消耗API调用额度
- 确保测试结果稳定可重复

如需测试真实AI调用，请配置有效的 `ai.qwen.api-key` 并使用 `@SpringBootTest` 集成测试。

## 7. 已知限制与后续改进

### 7.1 当前限制

1. **PatientServiceImpl单元测试**：由于继承了`ServiceImpl<PatientMapper, Patient>`，`lambdaQuery()`/`lambdaUpdate()`链式调用由MyBatis-Plus运行时提供，纯Mockito无法mock。单元测试仅覆盖输入校验逻辑，完整流程由集成测试覆盖
2. **PDF导出测试**：涉及iText库和文件系统IO，仅在集成测试中验证"报告不存在"场景
3. **Redis依赖**：集成测试需要Redis服务可用

### 7.2 后续改进建议

1. 引入H2内存数据库替代MySQL，消除集成测试对外部数据库依赖
2. 添加`@WebMvcTest`替代`@SpringBootTest`，加速Controller层测试
3. 添加Testcontainers支持MySQL/Redis容器化测试
4. 增加并发测试（预约号源竞态条件）
5. 添加JaCoCo插件生成覆盖率报告
6. 集成测试中添加数据库初始化/清理脚本（`@Sql`注解）
7. 将PatientServiceImpl重构为不继承ServiceImpl，改为注入Mapper+手动构建QueryWrapper，便于单元测试
