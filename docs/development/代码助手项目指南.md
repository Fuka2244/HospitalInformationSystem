# 代码助手项目指南

本文件为代码助手在本仓库中工作的项目指南。请先阅读本文件，再修改代码。

## 项目概览

这是一个医院信息系统（Hospital Information System, HIS），采用前后端分离架构：

- 后端：Spring Boot 3.2.5 + Java 21 + MyBatis Plus + MySQL + Redis + Kafka + JWT + LangChain4j + iText PDF。
- 前端：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Axios + Element Plus + ECharts。
- 后端接口统一前缀：`/HIS`。
- 前端开发代理基于 `frontend/vite.config.ts`，前端 API 封装在 `frontend/src/api/`。

主要角色：

- 患者：注册登录、个人信息、预约挂号、病历、药品查询、费用查询与支付、医疗报告。
- 医生：今日预约队列、叫号、接诊、结束就诊、生成病历、开具处方。
- 药师：处方审核、发药、药品库存、低库存预警、库存流水。
- 管理员：统计、用户/科室/排班管理、系统配置、周期统计报表。

## 常用命令

后端编译：

```bash
mvn -q -DskipTests compile
```

后端测试：

```bash
mvn test
```

后端启动：

```bash
mvn spring-boot:run
```

前端安装依赖：

```bash
cd frontend
npm install
```

前端开发启动：

```bash
npm run dev
```

前端构建：

```bash
npm.cmd run build
```

在 PowerShell 中优先使用 `npm.cmd`，避免 `npm.ps1` 被执行策略拦截。`mvnw.cmd` 在当前环境可能无法正常启动，优先使用本机 `mvn`。

## 目录地图

后端核心路径：

- `src/main/java/com/hospitalinfo/hospitalinformationsystem/controller/`：REST 控制器。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/service/`：服务接口。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/service/impl/`：业务实现。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/entity/`：MyBatis Plus 实体。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/dto/`：请求/响应 DTO。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/mapper/`：MyBatis Mapper。
- `src/main/java/com/hospitalinfo/hospitalinformationsystem/ai/`：AI 导诊、药品、费用、报告相关服务。
- `src/main/resources/sql/`：建表、扩展和演示数据脚本。
- `src/main/resources/application.yaml`：后端配置。

前端核心路径：

- `frontend/src/api/`：接口封装。
- `frontend/src/views/`：页面。
- `frontend/src/types/index.ts`：共享 TypeScript 类型。
- `frontend/src/router/index.ts`：路由和登录拦截。
- `frontend/src/stores/`：Pinia store。

## 关键业务模块

### 患者与账号

- 控制器：`PatientController`
- 服务：`IPatientService` / `PatientServiceImpl`
- 页面：`frontend/src/views/patient/ProfileView.vue`、`RecordsView.vue`
- API：`frontend/src/api/patient.ts`

支持患者注册、登录、JWT 登录、退出、刷新 token、个人资料查看/更新、病历和就诊历史查询。

### 预约挂号

- 控制器：`AppointmentController`
- 服务：`IAppointmentService` / `AppointmentServiceImpl`
- 实体：`Appointment`、`DoctorSchedule`
- 页面：`frontend/src/views/appointment/AppointmentView.vue`
- API：`frontend/src/api/appointment.ts`

支持：

- 创建预约
- 查询预约列表/详情
- 取消预约
- 改期
- AI 导诊推荐
- 查询可用排班
- 患者挂号登记
- 前台登记/现场挂号：`POST /appointment/frontdesk/registration`
- 查询就诊地点

注意：

- 预约创建使用分布式锁避免超卖号源。
- 登记成功会自动生成一条 `REGISTRATION` 挂号费账单。
- 登记返回数据包含 `appointment` 和确认 `message`。

### 门诊就诊与处方

- 控制器：`DoctorController`
- 服务：`IDoctorService` / `DoctorServiceImpl`
- 实体：`VisitRecord`、`MedicalRecord`、`Prescription`、`PrescriptionItem`
- 页面：`frontend/src/views/staff/DoctorWorkstation.vue`
- API：`frontend/src/api/doctor.ts`

医生工作台支持：

- 查看今日预约
- 叫号并分配就诊地点
- 开始接诊
- 结束就诊
- 查看患者历史病历
- 结束就诊时生成电子病历
- 结束就诊时可开具处方
- 处方生成后自动生成 `MEDICINE` 药品费用账单

`VisitRecordDto` 已扩展字段：

- `chiefComplaint`
- `presentIllness`
- `diagnosis`
- `treatment`
- `notes`
- `prescriptionItems`

### 药师与库存

- 控制器：`PharmacistController`
- 服务：`IPharmacistService` / `PharmacistServiceImpl`
- 实体：`PrescriptionAudit`、`MedicineInventory`、`MedicineStockLog`
- 页面：`frontend/src/views/staff/PharmacistWorkstation.vue`
- API：`frontend/src/api/pharmacist.ts`

支持：

- 查询待审处方
- 审核处方
- 发药
- 药品库存维护
- 低库存查询
- 库存流水查询

注意：

- 发药前会检查处方是否审核通过。
- 发药时会校验库存是否足够。
- 发药成功会扣减 `medicine_inventory.quantity`，并写入 `medicine_stock_log`。

### 药品查询

- 控制器：`MedicineController`
- 服务：`IMedicineService` / `MedicineServiceImpl`
- 页面：`frontend/src/views/medicine/MedicineView.vue`
- API：`frontend/src/api/medicine.ts`

支持药品列表、详情、AI 药品推荐、AI 药品问答。

### 费用查询与支付

- 控制器：`BillingController`
- 服务：`IBillingService` / `BillingServiceImpl`
- 实体：`Billing`
- 页面：`frontend/src/views/billing/BillingView.vue`
- API：`frontend/src/api/billing.ts`

支持：

- 当前患者费用列表
- 指定患者费用列表
- 费用详情
- AI 费用解释
- AI 费用多轮问答
- 单笔支付：`PUT /billing/{id}/pay`
- 一键支付全部未支付费用：`PUT /billing/pay-all`

账单状态：

- `0`：未支付
- `1`：已支付
- `2`：已退款

支付功能当前是系统内状态流转，不接第三方支付渠道。支付后会将账单状态置为已支付，并把支付方式追加到 `description`。

### 医疗报告

- 控制器：`MedicalReportController`
- 服务：`IMedicalReportService` / `MedicalReportServiceImpl`
- 实体：`MedicalReport`
- 页面：`frontend/src/views/report/ReportView.vue`
- API：`frontend/src/api/report.ts`

支持：

- AI 生成报告
- SSE 流式生成报告
- 报告列表
- 报告详情
- PDF 导出
- 报告确认

### 管理员统计

- 控制器：`AdminController`
- 服务：`IAdminService` / `AdminServiceImpl`
- 页面：`frontend/src/views/staff/AdminConsole.vue`
- API：`frontend/src/api/admin.ts`

支持：

- 基础统计：`GET /admin/statistics`
- 全局统计：`GET /admin/global-statistics`
- 周期统计报表：`GET /admin/periodic-report`
- 系统配置
- 用户管理
- 科室管理
- 排班管理

周期统计报表包含预约数量、完成/取消数量、收入、已支付金额、未支付数量、低库存药品等。

## 编码约定

后端：

- Controller 只做参数接收、权限轻校验、调用 Service。
- 业务逻辑放在 `service/impl`。
- 数据访问使用 MyBatis Plus Mapper，不要在 Controller 中直接访问 Mapper。
- 返回统一使用 `Result.ok(...)` / `Result.fail(...)`。
- 涉及多表写入的业务必须加 `@Transactional`。
- 新增接口时同步更新 service interface、service impl、controller、前端 api、前端 types。
- 新增 DTO 放在 `dto/`，实体字段和数据库字段用 `@TableField` 对齐。

前端：

- API 调用统一写在 `frontend/src/api/`。
- 类型统一补充到 `frontend/src/types/index.ts`。
- 页面优先使用 Element Plus 组件。
- 员工端页面在 `frontend/src/views/staff/`。
- 构建验证使用 `npm.cmd run build`。

## 当前业务闭环

预约流程：

1. 患者登录。
2. 选择科室、医生、排班时间。
3. 提交预约。
4. 系统创建预约并占用排班号源。
5. 患者或前台登记。
6. 系统生成挂号费账单。
7. 医生叫号，写入就诊地点。

门诊流程：

1. 医生查看今日预约。
2. 医生叫号。
3. 医生开始接诊。
4. 医生结束就诊，保存诊断、治疗方案。
5. 系统生成电子病历。
6. 若填写处方，系统生成处方、处方明细和药品费用。
7. 药师审核处方。
8. 药师发药，系统扣库存并写流水。
9. 患者在费用页面支付账单。

## 工作注意事项

- 仓库当前可能存在大量未跟踪文件、测试报告和构建产物，修改前先看 `git status --short`。
- 不要回滚用户已有改动。
- 不要随意重写 SQL 演示数据，除非任务明确要求。
- 后端 Maven 首次编译可能需要访问 Maven Central 下载依赖。
- AI、Kafka、Redis 相关功能依赖本地服务配置；普通编译不需要它们运行。
- 如果接口路径变更，请同步更新前端 API 和页面调用。
- 如果修改实体字段，请同步检查 SQL 脚本、DTO、前端类型和页面展示。
