# 项目文档

本目录集中存放医院信息系统的设计、开发、测试与演示资料。

- `architecture/`：系统架构、技术路线、详细设计及药品 AI 检索架构
- `api/`：API 开发说明与 OpenAPI 定义
- `development/`：开发文档与代码助手项目指南
- `testing/`：测试方案、Postman 文档及安全性、可用性测试报告
- `troubleshooting/`：故障排查指南
- `presentation/`：项目演示方案与面试题库

自动生成的 PDF 报告、评价结果、上传文件和本地运行数据不纳入版本控制。

本地开发和测试辅助命令见 [`scripts/`](../scripts/README.md)。
